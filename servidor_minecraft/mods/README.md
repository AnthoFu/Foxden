# Carpeta de Mods de Minecraft (Foxden 🦊)

Colocá acá tus archivos de mods con extensión `.jar` (para **Fabric** o **Forge**) antes de iniciar el servidor.

> 💡 **Notas importantes:**
> - Asegurate de que los mods que agregues correspondan a la versión exacta de Minecraft y al cargador (**Fabric** o **Forge**) que tengas seleccionado en la pestaña **Versiones e Instalador** del panel.
> - Los archivos `.jar` colocados acá están protegidos por el `.gitignore` del proyecto para evitar que el repositorio se vuelva pesado si decidís subir cambios a GitHub.
